# Invariants (Phase 2)

Run `2026-11-17-295d64b`. Sources: the ten generic invariants of the plan (all apply) and the
Claims inventory (`inventory.md` section 16). Row ids refer to `inventory.md`.

Status at this stage, before any lens has run:

- **holds**: the enforcing code path was read and produces the property unambiguously, and a test covers it;
- **holds (untested)**: the code path produces it, but no automated test does;
- **violated**: the code or the register already shows a counterexample (register id or code path given);
- **unverified**: needs a lens reviewer or a live test to decide.

Per the plan, an invariant with no enforcement point or no test is itself a finding; those
are marked **gap** and handed to the lenses for confirmation.
