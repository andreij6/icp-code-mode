# Coverage grid: L11 Sandbox and determinism, round 1

Run `2026-11-17-295d64b`. Lens question: can untrusted code or input reach something it
should not (dynamic evaluation, time, randomness, host access, state surviving between runs,
escaping a wrapper, influence over a later run)?

Method: code reading of `src/runtimes/{js,python,rhai_rt}.rs`, `src/bridge.rs`, `src/lib.rs`
(getrandom backend), `shims/web-time`, and the engines' sources (boa_engine 0.22.0,
monty/monty-types 1.6.0, rhai 1.27.0, ahash 0.8.12, foldhash 0.2.0) in the cargo registry.
Dynamic: native probe tests added to a private copy (`git archive HEAD`, shared
`CARGO_TARGET_DIR`, copy deleted afterwards) and non-destructive script runs against the
local `icp_code_mode` canister on port 8010 (no deploy, no setting changed). One probe
deliberately hit the 40B per-message trap once (finding L11-1).

Evidence key: **R** reproduced, **C** code path only.
